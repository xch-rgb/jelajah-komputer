INPUT

Keyboard

Memasukkan huruf, angka, simbol, dan perintah ke komputer.

Contoh penggunaan: mengetik tugas di aplikasi pengolah kata. Keyboard termasuk perangkat keras masukan.
INPUT

Mouse

Menggerakkan penunjuk untuk memilih, mengeklik, dan menyeret objek.

Coba klik ikon, pilih menu, atau seret berkas pada komputer. Touchpad laptop memiliki fungsi serupa.
OUTPUT

Monitor

Menampilkan teks, gambar, video, dan hasil pengolahan data.

Monitor adalah perangkat keluaran visual. Proyektor juga menampilkan gambar, tetapi ke layar yang lebih besar.
OUTPUT

Speaker

Mengeluarkan suara, musik, dan audio dari komputer.

Headset juga merupakan perangkat keluaran audio. Periksa volume agar tidak mengganggu orang lain.
PROSES

CPU / Prosesor

Menjalankan instruksi dan mengolah data sesuai program.

CPU sering disebut “otak” komputer. Kecepatan kerja juga dipengaruhi RAM, penyimpanan, dan komponen lainnya.
MEMORI KERJA

RAM

Menyimpan sementara data dan program yang sedang digunakan.

RAM bersifat sementara. Saat komputer dimatikan, isi RAM tidak dipertahankan seperti berkas di SSD atau HDD.
PENYIMPANAN

SSD / HDD

Menyimpan sistem operasi, aplikasi, dan berkas agar tetap ada saat mati.

SSD umumnya lebih cepat dan tidak memiliki piringan berputar. HDD biasanya memakai piringan magnetik.
PENYIMPANAN

Flashdisk

Media portabel untuk memindahkan dan menyimpan berkas.

Selalu gunakan fitur eject atau keluarkan dengan aman sebelum mencabut flashdisk dari komputer.
PERANGKAT LUNAK

Aplikasi

Program untuk membantu tugas tertentu, seperti mengetik atau menggambar.

Contoh: LibreOffice Writer untuk dokumen, browser untuk membuka web, dan aplikasi presentasi untuk membuat slide.
